# apps/ — встроенные MVP

Каждая папка `apps/<slug>/` — один MVP, который открывается на сайте по адресу `/apps/<slug>/demo/`.
`<slug>` должен совпадать с именем файла описания в `src/content/apps/<lang>/<slug>.mdx`, а в описании нужно указать `demoType: embedded`.

Скрипт `scripts/build-demos.mjs` запускается сам перед `npm run dev` и `npm run build` и кладёт готовые MVP в `public/apps/<slug>/demo/`.

## Два вида MVP

1. **Статический** (как `rice-calculator`): просто `index.html` и файлы рядом. Копируется как есть.
2. **С собственной сборкой** (Vite, React, Svelte и т.д.): в папке есть `package.json` со скриптом `build`, результат в `dist/`.
   Скрипт выполнит `npm ci` (или `npm install`) и `npm run build`, затем скопирует `dist/`.
   В `vite.config` обязательно укажите `base: './'`, чтобы ссылки на файлы работали в подпапке.

## Правила
- MVP не зависит от сайта: свои стили, свои скрипты. Сломанный MVP не ломает портфолио.
- Ссылка «назад» из MVP: `href="../"` ведёт на страницу описания.
- Данные пользователя хранить только в браузере (localStorage с try/catch). MVP с сервером выносятся на внешний хостинг, см. Reference.md, раздел 9, вопрос 3.
