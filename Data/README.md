# Data — личные исходники владельца

Папка для исходных материалов: фото, тексты резюме, CV. Это **источник**, а не часть сайта.
Claude Code берёт отсюда данные и раскладывает их по полям профиля сайта (см. Reference.md, раздел 3.4).

Папка исключена из git через `.gitignore`: в публичный репозиторий попадают только обработанные материалы
(сжатое фото, тексты без телефона и личных адресов).

## Что и куда положить

### `photo/`
- Основное фото: файл `portrait.jpg` или `portrait.png`.
- Требования: реальная фотография, квадрат или вертикальный портрет, минимум 1200 px по короткой стороне, нейтральный фон, лицо занимает 40–60% кадра.
- Можно положить несколько вариантов, Claude предложит лучший для hero и About.

### `resume/`
- `resume-ru.md` (или .docx / .txt): текущее резюме на русском.
- `resume-en.md`: на английском, если есть. Если нет, Claude сделает первый черновик перевода, вы вычитаете.
- Полезно добавить: 3–4 главных достижения с цифрами, список компетенций, ссылки на соцсети (LinkedIn, Telegram, GitHub).

### `cv/`
- Текущие CV в любом формате (PDF, DOCX). Используются как справочник по опыту, датам и формулировкам.

## Что НЕ попадёт на сайт без явного согласия
Телефон, домашний адрес, дата рождения, паспортные и иные идентифицирующие данные. Если они есть в исходниках, Claude их пропустит.
